# Персональный сайт Алексея Пахалко

Статический сайт ведущего геолога на Astro + TypeScript. Весь текст и фото доступны без JavaScript; скрипт (3 КБ gzip) добавляет карусели, полноэкранный просмотр и анимации. Исходные резюме, фото, сертификаты и презентации не изменяются.

## Запуск

Нужен Node.js 22.12+. На этой машине задан `NODE_ENV=production`, поэтому dev-зависимости ставятся так:

```powershell
$env:NODE_ENV='development'; npm install --include=dev
npm run dev        # http://127.0.0.1:4321/ru/ (если после правки схемы пропали этапы: Ctrl+C, удалить .astro\data-store.json, снова npm run dev)
npm run check      # типы и схемы контента
npm run build      # результат в dist/
npm run test:browser  # скриншоты и проверки в Microsoft Edge -> review/
```

`scripts/review.mjs` сам поднимает сервер для `dist/`, снимает десктоп (1440) и телефон (390) и проверяет карусель, просмотр крупно (стрелки, Escape, синхронизация с каруселью), что рамки галерей совпадают с пропорциями фото, что в просмотре крупно вертикальные и горизонтальные фото видны целиком и заполняют экран (1440×900, 1366×657, 390×844, 844×390), страницу кейса, отсутствие горизонтального переполнения и ошибок консоли.

## Дизайн

Концепция «полевой атлас под микроскопом». Подробности в комментарии в начале `src/styles/global.css`.

- Цвета взяты из дизайн-токенов Rocksurv Classifier (`#FDFDF5`, `#2E6B34`), поэтому сайт и приложения выглядят как одно семейство. Блок приложений и страницы кейсов в ночной теме.
- Шрифт один: Geologica (кириллица, ось SHRP). Заголовки с острыми «кристаллическими» гранями, текст мягкий.
- Герой: портрет и круг поляризационного микроскопа со шлифом изменённого габбронорита (николи скрещены). Это единственное изображение, взятое из презентации (Herlany 2019, слайд 8): `prepare_media.py` читает его прямо из .pptx и пишет `public/images/scope-gabbronorite-*.webp`. При прокрутке столик поворачивается, яркость проседает, как при погасании зёрен (Chrome/Edge/Safari с scroll-driven animations; в остальных браузерах круг статичен).
- Опыт: липкая стратиграфическая колонка. Знаки слоёв подобраны по породам этапов (граниты щита, базальты Эмэйшаня, кварцевые жилы, габбро, гнейсы), слой текущего этапа подсвечивается.
- Карусели: снэп-скролл с соседними кадрами, глубина и параллакс при листании, перетаскивание мышью с броском, лента превью, клавиатура. Фото открывается крупно с морфингом из слайда (View Transitions API), листается стрелками и свайпом; при закрытии карусель встаёт на последний просмотренный кадр.
- Переходы: занавес загрузки героя, проявление блоков при прокрутке, блок приложений раскрывается из карточки на всю ширину, шапка темнеет над ним, заголовок и диаграмма приложения перетекают на страницу кейса.
- Сетка Шмидта и треугольник QAPF считаются при сборке по формулам из спецификации (`src/components/Stereonet.astro`, `Qapf.astro`).
- Всё движение отключается при `prefers-reduced-motion`.

## Содержание

Записи в `src/content/*.json`, схемы в `src/content.config.ts`. Выводятся только записи с `publicationState: published`. У каждой записи есть `evidence`: источник и признак проверки по документу. В видимом тексте запрещены длинные и средние тире (проверяется схемой).

- `experience.json`: семь этапов, 28 фото из `photo/`. Поля `place`, `short` (подпись в колонке), `pattern` (знак слоя). У фото `date` (год съёмки или год и месяц) выводится плашкой на снимке и в подписи просмотра крупно.
- `apps.json`: `kind: product` получает страницу кейса (Rocksurv Field, Rocksurv Classifier, Rocksurv Core и RockSurv Petrography), `kind: practice` выводится блоком «Из практики GMAS» (VBA-проверка журналов, Android-приложение, по резюме).
- `credentials.json`: награды и аккредитация, сертификаты, образование, публикации, доклады. У докладов поле `file` ведёт на PDF презентации.

### Фото по годам

- В галереях только собственные фото из `photo/`. Схема и `prepare_media.py` не пропустят другой источник. Изображения из презентаций в галереи не вырезаются (исключение только шлиф в круге на первом экране).
- `date` берётся из EXIF (`DateTimeOriginal`) или из имени файла. Если даты нет (копии из мессенджеров, сброшенные часы камеры), поле не ставится.
- Синхронизация по годам проверяется при сборке: снимок, чей год не входит в годы этапа (`period`), останавливает сборку с сообщением вроде «china-emeishan: снимок 2014-02 не входит в годы этапа «2011-2012»».
- Внутри этапа снимки идут от новых к старым, как и сами этапы.

### Как добавить фото этапа

1. Положите оригинал в `photo/<папка>/`.
2. Добавьте запись в `photos` этапа: `slug`, `source`, `date` (если известна), `alt` (что видно) и `caption` (без даты, её добавит плашка).
3. `uv run --python-preference only-managed --with pillow python scripts/prepare_media.py`. Скрипт делает WebP 160, 640 и 1280 px без EXIF/GPS (и 1920 px, если оригинал крупнее 1536 px: его берёт просмотр крупно на больших и Retina-экранах), записывает размеры и средний цвет в `src/data/photo-sizes.json`, обновляет портрет и копию CV. В карусели каждая рамка повторяет пропорции своего фото, поэтому вертикальные и горизонтальные снимки можно смешивать свободно.
4. `npm run build`. Если веб-копии нет или дата не совпадает с годами этапа, сборка остановится с подсказкой.

### Презентации докладов

Презентации из `materials/` публикуются целиком, как PDF в `public/talks/`, и открываются из раздела «Доклады и лекции». Экспорт через PowerPoint:

```powershell
uv run --python-preference only-managed --with pywin32 python scripts/export_talks.py            # только недостающие
uv run --python-preference only-managed --with pywin32 python scripts/export_talks.py --force    # пересобрать все
```

Скрипт записывает размеры файлов в `src/data/talk-sizes.json` для подписей «PDF, 6,5 МБ». Новую презентацию добавьте в словарь `TALKS` в скрипте и в поле `file` доклада.

## Политика ассетов и репозиторий GitHub

- **Исходные материалы (~406 МБ):** папки `photo/`, `materials/`, `certificate/` и `CV/` содержат оригиналы фотокамеры, презентации PowerPoint, сканы документов и файлов резюме. Они исключены из Git-репозитория через `.gitignore`, сохраняя историю репозитория компактной и защищая исходные персональные файлы.
- **Публичные веб-копии (`public/`):** сгенерированные оптимизированные WebP-снимки, экспортированные PDF-презентации и итоговые документы находятся в `public/` и отслеживаются репозиторием. Это позволяет разворачивать сайт (GitHub Pages, Vercel и др.) и запускать локальный сервер без необходимости иметь на машине и пересобирать 400+ МБ исходников.
- **Размеры и метаданные:** все пропорции и цветовые заглушки зафиксированы в `src/data/photo-sizes.json` и `src/data/talk-sizes.json`, благодаря чему валидация схем и сборка (`npm run build`) работают автономно.

## Обновление презентации Rocksurv Field

На сайте используется двуязычный комплект v14 от 7 октября 2026 года: 17 слайдов о геологическом и геохимическом сборе, офлайн-картах, высотных профилях и передаче проб.

Положите исходный ZIP в `materials/` и выполните с Python и Pillow:

```powershell
python scripts/update_field_presentation.py --kit materials/Rocksurv_Field_Presentation_Kit_EN_RU_v14.zip
npm run build
node scripts/test_presentations.mjs
```

Скрипт сохраняет управление презентацией на сайте, заменяет содержимое RU/EN, оптимизирует снимки в WebP и обновляет число слайдов и изображения на главной и страницах приложения. Для следующих версий Field используйте этот скрипт; `build_optimized_presentations.py` содержит прежний шаблон v13.

## Rocksurv Core

Третье приложение линейки: документация керна и горных выработок. Описание в `src/content/apps.json` и `apps.en.json` составлено по 14-слайдовым презентациям из `materials/Rocksurv-Core/`. Готовый графический движок, разрабатываемый MVP и последующие модули обозначены отдельно, согласно дорожной карте на слайде 12.

Для обновления презентаций с Python и Pillow:

```powershell
python scripts/import_core_presentations.py --source 'C:\AppProjects\Rocksurv Core\docs\presentation'
npm run build
node scripts/test_presentations.mjs
```

Карточка Core и страница приложения используют локализованные снимки из презентации. Метаданные ссылок на презентации находятся в `src/data/app-presentations.ts`.

## RockSurv Petrography

Отдельное приложение для оптической минералогии и петрографии: определитель минералов, атлас шлифов, парные PPL/XPL фотографии, номограмма Мишель-Леви и практикум. Описание составлено по `materials/RockSurf_Petrography_Presentation_Kit_EN_RU.zip`. Classifier сохраняет свою специализацию на классификации пород и структурном анализе.

Для обновления HTML-презентаций, снимков и оригинальных PDF с Python и Pillow:

```powershell
python scripts/import_petrography_presentations.py --kit materials/RockSurf_Petrography_Presentation_Kit_EN_RU.zip
npm run build
node scripts/test_presentations.mjs
```

Карточка, страница описания и презентация доступны на русском и английском языках. При импорте название нормализуется к RockSurv Petrography в HTML и PDF.

В профиле используется профессиональное обозначение «ведущий геолог» / «Senior Geologist». Должность ведущего инженера в Институте Карпинского сохраняется. Геохимический модуль Field предназначен для поисков полезных ископаемых по ореолам рассеивания. Публичные резюме нормализуются через `scripts/cv_identity.py`; исходные документы остаются нетронутыми.
